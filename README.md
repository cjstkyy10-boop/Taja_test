# ⌨️ 초등학교 학급용 실시간 한글 타자 경시대회 웹앱

초등학교 컴퓨터실 또는 교실에서 **최대 30명(학급 전체)**의 학생들이 동시에 접속하여 긴 글 한글 타자 검정 시험을 치르고, 선생님이 실시간으로 학생들의 타자 속도, 오타수, 정확도를 중계하며 결과를 엑셀(CSV)로 다운로드할 수 있는 멘티미터/카훗 스타일의 웹 애플리케이션입니다.

---

## 🌟 주요 기능

### 1. 선생님(관리자) 화면 (`/teacher`)
- **멘티미터 스타일 대형 빔프로젝터/전자칠판 뷰**:
  - 교실 내 Wi-Fi / 유선 LAN 접속 주소 자동 안내 (예: `http://192.168.0.x:3000`)
  - 6자리 방 번호(PIN) 대형 표시
  - 스마트폰 / 태블릿 / 크롬북 즉시 접속용 QR코드 자동 생성
- **대기실 실시간 학생 명단**:
  - 학생이 접속할 때마다 귀여운 동물 아바타 + 번호 + 이름 카드가 실시간으로 등장
  - 접속 학생 수 실시간 카운트 (`현재 28 / 30명`)
  - 장난치거나 잘못 들어온 학생 퇴장(Kick) 기능
- **수준별 긴 글 지문 선택 및 커스텀 지문 입력**:
  - [초등 저학년] 황순원 <소나기>
  - [초등 중학년] 생텍쥐페리 <어린 왕자>
  - [초등 고학년] 세종대왕 <훈민정음 서문>
  - [상식] 애국가 1~2절
  - [따뜻한 동화] 권정생 <강아지 똥>
  - [문학] 윤동주 <서시>
  - **선생님 직접 입력/수정**: 교과서 지문이나 알림장 내용 등을 직접 복사/붙여넣기하여 시험 출제 가능!
- **실시간 경기 중계 대시보드 (레이싱 뷰)**:
  - 30명 학생 각각의 타자 진행률과 타자 속도(타/분), 오타수, 정확도가 실시간 레이싱 바 형태로 전진!
  - 학급 실시간 평균 타수, 완주 학생 수 집계
- **명예의 전당 & 시상대 (포디움)**:
  - 1위(금), 2위(은), 3위(동) 메달 시상대 + 축하 폭죽 애니메이션
- **전체 학급 성적표 & 엑셀(CSV) 다운로드**:
  - 순위, 번호, 이름, 최고 타수, 정확도, 오타수, 소요시간(초), 완주 여부 테이블 제공
  - 클릭 한 번으로 **한글 깨짐 없는 Excel 호환 CSV 다운로드** (UTF-8 BOM 탑재)

### 2. 학생 화면 (`/`)
- **간편한 입장**:
  - 방 번호(PIN 6자리) + 출석 번호 + 이름 입력 후 즉시 입장
- **직관적인 타자 검정 인터페이스**:
  - 한글 2벌식 표준 타수 계산 알고리즘 (초성/중성/종성 자모 분해 완벽 지원)
  - 입력하는 글자별 실시간 색상 피드백 (맞으면 연두색, 틀리면 빨간색 밑줄, 현재 위치 노란색 깜빡임)
  - 백스페이스를 통한 실시간 오타 수정 지원
  - 현재 타수(타/분), 오타수, 정확도(%), 경과 시간 실시간 표시
- **시험 완료 리포트**:
  - 개인별 최고 타수, 정확도, 오타수, 걸린 시간, 학급 내 완주 순위 확인

## 🚀 실행 방법

### 방법 1: 바탕화면에서 더블 클릭 (가장 쉬움)
폴더 안의 **`시작하기.bat`** 파일을 더블 클릭하면 자동으로 서버가 실행되고 선생님 화면이 브라우저에 열립니다.

### 방법 2: 터미널 명령어로 실행
```bash
npm start
```

## 🏫 교실 수업 진행 가이드 (선생님 팁)

1. **선생님 컴퓨터에서 `시작하기.bat` 실행**
   - 자동으로 브라우저에 선생님 화면(`http://localhost:3000/teacher`)이 열립니다.
2. **전자칠판 / 빔프로젝터에 선생님 화면 띄우기**
   - 화면 상단에 표시되는 **방 번호(PIN 6자리)**와 **접속 주소(예: `http://192.168.0.x:3000`)**를 학생들에게 안내합니다.
3. **학생들 접속**
   - 학생 컴퓨터(크롬/엣지)에서 해당 주소로 접속한 뒤 방 번호와 본인 번호, 이름을 입력합니다.
   - 선생님 화면에 학생들이 들어올 때마다 동물 카드가 쏙쏙 나타납니다.
4. **지문 선택 후 [시험 시작하기!] 클릭**
   - 3, 2, 1 카운트다운과 함께 모든 학생 화면에서 일제히 시험이 시작됩니다.
5. **실시간 레이싱 중계**
   - 빔프로젝터에서 학생들이 타이핑하는 진행률과 타수가 실시간으로 달리기하듯 움직여 수업 집중도가 높아집니다.
6. **결과 발표 및 엑셀 다운로드**
   - 모든 학생이 완주하면 자동으로 1, 2, 3위 시상대와 전체 성적표가 나타납니다.
   - **[성적표 엑셀(CSV) 다운로드]** 버튼을 눌러 보관할 수 있습니다.
